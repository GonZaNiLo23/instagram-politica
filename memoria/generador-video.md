# Memoria · generador-video

## Entorno
- [entorno] No hay Python en el equipo: los scripts auxiliares se escriben en Node (`.mjs`). En Git Bash, antes de nada: `export PATH="/c/Program Files/nodejs:$PATH"`. (2026-10-20)
- [entorno] ffmpeg y ffprobe los localiza `videos/scripts/herramientas.mjs`; desde Bash, búscalos con `where ffmpeg` si los necesitas sueltos. (2026-10-20)
- [render] `node videos/scripts/render.mjs NNN-slug --v=vX` hace todo (props, render, -14 LUFS, ffprobe, 6 fotogramas de control y portada). No hace falta lanzar `npx remotion render` a mano. Cada pieza usa su carpeta como `--public-dir`, así que se pueden renderizar varias piezas a la vez. (2026-10-20)
